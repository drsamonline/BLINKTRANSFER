Send a file with light.

BlinkTransfer moves files between two devices using only a screen and a camera. One shows an animated QR code, the other points its camera at it. No internet, no Bluetooth, no cables, no pairing — nothing leaves the room.

Open the app View source

Why it is different

Rateless coding

Frames are fountain-coded, not an ordered list. Miss one, or twenty, and the transfer still finishes — you only need enough good frames.

Any-scanner mode

Send a small text file as one plain QR that any phone camera app can read. No second device running BlinkTransfer needed.

Truly offline

A fully installable PWA. After the first load it never touches the network — built for air-gapped rooms and dead zones.

Light on dependencies

Two small, well-known libraries and nothing else at runtime. Works on the cheapest phones and in poor light.

How it works

files ─▶ gzip ─▶ k blocks ─▶ LT fountain symbols ─▶ QR frames (looping)
                                                              │
  files ◀─ gunzip ◀─ reassemble ◀─ LT decode ◀─ jsQR ◀─ camera ┘
1. SendPick files on the sending device. They are compressed and coded into a loop of QR frames.
2. ReceivePoint the other camera at the code. Frames are collected in any order.
3. SaveWhen enough frames arrive, the file is reassembled and checked, ready to save.
